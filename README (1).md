# Phân chia công việc 

Dự án được chia thành các phần chính gồm: common, client, server, database, DAO và connection.

Hiện tại, nhóm phân công công việc như sau:

## Thành viên và phần việc

### 1\. Bùi Tiến Dũng

\-Phụ trách phần `common`

\-Công việc chính:

+Xây dựng các class dùng chung cho toàn hệ thống

+Thiết kế model/entity cơ bản

+Khai báo các enum, constant dùng chung

+Chuẩn hóa cấu trúc dữ liệu để client, server và database có thể sử dụng thống nhất

### 2\. Đức Quang

\-Phụ trách phần client, server



\-Công việc dự kiến:

+Xây dựng giao diện người dung

+Xử lý tổng quát toàn bộ app

+Xử lý tương tác phía người dùng

+Kết nối dữ liệu từ client tới server

### 3\. Minh Dũng

\-Phụ trách phần server,client



\-Công việc dự kiến:

+Xây dựng giao diện người dùng

+Xây dựng logic xử lý nghiệp vụ phía server

+Tạo API hoặc các cơ chế giao tiếp giữa client và server

+Xử lý request, response và luồng dữ liệu hệ thống

### 4\. Bình

\-Phụ trách phần database, DAO và connection

\-Công việc chính:

+Thiết kế cơ sở dữ liệu

+Tạo bảng và xây dựng quan hệ dữ liệu

+Viết các lớp DAO để thao tác với dữ liệu

+Xây dựng phần connection để kết nối hệ thống với cơ sở dữ liệu

## Tóm tắt phân công

|Thành viên|Phần phụ trách|Trạng thái|
|-|-|-|
|Bùi Tiến Dũng|Common|Đang thực hiện|
|Đức Quang|Client,Server|Đã xong Client, đang làm server|
|Minh Dũng|Client,Server|Đã xong Client|
|Bình|Database, DAO, Connection|Đang thực hiện|
